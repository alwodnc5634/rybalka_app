ЧТО НОВОГО (v8): «Ловля спиннингом с берега» переделана по реальному
протоколу + исправлен баг с разрядами
===========================================================================

Разобран присланный реальный протокол Чемпионата Вологодской области
(28.09.2025) — по нему дисциплина «Ловля спиннингом с берега» приведена в
соответствие с тем, как соревнование проходит на самом деле.

1. ТУРОВ БОЛЬШЕ НЕТ — только ПЕРИОДЫ. Раньше программа считала «туры, а
   внутри туров периоды». В реальности тур всегда один, и в протоколе его
   нет вообще: есть только периоды (обычно 3). Настройка «количество туров»
   убрана, осталось «количество периодов».

2. ЗОНА — НА КАЖДЫЙ ПЕРИОД ОТДЕЛЬНО. В реальном протоколе так и написано:
   «Зона 1пер», «Зона 2пер», «Зона 3пер» — спортсмен переходит из зоны в
   зону между периодами. Раньше зона задавалась одна на весь тур.

3. ПРИ РЕГИСТРАЦИИ ЗОНА БОЛЬШЕ НЕ СПРАШИВАЕТСЯ. Регистрация идёт до начала
   соревнования, когда жеребьёвки ещё не было — поэтому поля зоны из формы
   регистрации убраны совсем.

4. НОВАЯ ВКЛАДКА «ЖЕРЕБЬЁВКА» (между «Регистрацией» и «Печатью карт»).
   Там таблица: строка — спортсмен, столбцы — зоны по каждому периоду.
   Можно заполнить вручную (выбор в списке сохраняется сразу), а можно
   нажать «Провести жеребьёвку автоматически» — программа случайно разделит
   участников на группы и проведёт их по зонам С РОТАЦИЕЙ (в каждом периоде
   группа переходит в следующую зону), заодно назначит стартовые номера.
   После автоматической жеребьёвки любую строку можно поправить руками.

5. В ПРОТОКОЛ ДОБАВЛЕНО КОЛИЧЕСТВО РЫБ ПО КАЖДОМУ ПЕРИОДУ. Теперь на каждый
   период в протоколе четыре столбца: зона, количество рыб, баллы (сумма
   длины) и место в зоне. Дальше — сумма мест, всего рыб, общая сумма см и
   итоговое место.

6. КОМАНДНЫЙ ЗАЧЁТ для этой дисциплины (в присланном файле есть листы
   «Команда» и «Командно-Личный»). Баллы команды = сумма мест всех её
   участников по всем периодам; место — по этой сумме, при равенстве
   выигрывает команда с большей суммарной длиной, затем — с большим
   количеством рыб. Отбора «лучших N» нет — считаются все участники
   команды. Командный протокол печатается вместе с личным, а на вкладке
   «Разряды» появились и командные нормативы (раньше программа их для этой
   дисциплины не считала вовсе).

7. ПОДСЧЁТ ПО ВЕСУ (правила муниципальных соревнований). На соревнованиях
   уровня муниципального образования рыбу не измеряют сантиметрами, а
   ВЗВЕШИВАЮТ, и всё считается один в один как в донке. Поэтому добавлен
   переключатель «Подсчёт ПО ВЕСУ»:
     - при создании турнира — галочка сразу в списке турниров;
     - в уже созданном турнире — галочка в «Данных турнира»; при выборе
       статуса «Чемпионат муниципального образования» она предлагается
       автоматически, но её можно снять.
   Во включённом виде турнир ведётся доночным экраном: туры, зона на тур,
   одно взвешивание за тур, периодов нет; название дисциплины при этом
   остаётся «Ловля спиннингом с берега», и разряды считаются по нормативам
   именно этой дисциплины. Переключить способ подсчёта можно, только пока
   не зарегистрирован ни один спортсмен (два способа хранят данные
   по-разному) — программа об этом честно предупредит.

8. ИСПРАВЛЕН БАГ С РАЗРЯДАМИ. В прошлой версии спортсмену, у которого уже
   есть КМС, программа могла «присвоить» 1 или 2 разряд. Теперь разряд
   присваивается, только если он ВЫШЕ имеющегося; иначе в протоколе
   разрядов пишется «норматив выполнен, разряд подтверждён».

9. В ПРОТОКОЛЫ ВСЕХ ДИСЦИПЛИН ДОБАВЛЕНЫ СТОЛБЦЫ «РАЗРЯД ДО» И «РАЗРЯД
   ПОСЛЕ» (как в реальных протоколах). «После» заполняется автоматически по
   расчёту ЕВСК: если спортсмен выполнил более высокий норматив — там будет
   новый разряд (выделен цветом), если только подтвердил имеющийся — тот же
   самый. Берётся лучшее из личного и командного норматива.

Тай-брейк при полном равенстве (для подсчёта по длине): сначала сумма мест,
затем суммарная длина, затем общее количество рыб, затем КОЛИЧЕСТВО РЫБ В
ПОСЛЕДНЕМ ПЕРИОДЕ (при равенстве — в предпоследнем, и так далее назад), и
только если совпало вообще всё — места делятся поровну (среднее
арифметическое, как и раньше). Для подсчёта по весу — в точности как в
донке.

Что будет со старыми турнирами этой дисциплины: при первом открытии
программа сама переведёт их на новую структуру — зона 1-го тура встанет
всем периодам, карты 1-го тура сохранятся как есть. Данные 2-го тура
отбрасываются (туров в дисциплине больше нет). Регистрация, судьи, команды
и спортсмены не затрагиваются.

ЧТО НОВОГО (v7): разряды (ЕВСК), полузоны, автоматическая жеребьёвка
===========================================================================

Реализованы все 3 пункта, которые в v6 были сознательно отложены "на потом"
(они не блокировали работу программы, поэтому и попали в v6 без них).

1. РАЗРЯДЫ (ЕВСК) — новая вкладка «Разряды» на всех экранах дисциплин.
   Считает, какой спортивный разряд (МСМК/МС/КМС/1-3 разряд/1-3 юношеский)
   выполнил каждый спортсмен (и команда, где это применимо) по итогам
   турнира — по нормативам официального документа "Приложение № 61 к
   приказу Минспорта России от 9 апреля 2026 г. № 299", который вы
   присылали. Как это устроено:
     - На вкладке «Регистрация» у турнира появилось поле «Статус
       соревнования» (ранг турнира: первенство России, чемпионат региона
       и т.п. — от этого зависит, какой разряд вообще можно получить).
     - Программа проверяет: место в итоговом протоколе, число участников
       (у большинства разрядов есть минимум по числу участников — если
       участников заявленного статуса турнира не хватает, программа сама
       проверяет по нормативам СЛЕДУЮЩЕГО по статусу турнира, как и
       положено по правилам), нулевой улов (всегда без разряда, независимо
       от места), и то, что уже подтверждено (например, чтобы получить МС,
       нужно уже иметь КМС — если не хватает КМС, но есть 1 разряд и
       выполнены нормативы МС, засчитывается выполнение КМС — это прямо
       написано в самом документе как исключение, и оно реализовано).
     - Для командных дисциплин (донка/поплавок/блесна/мормышка — командный
       протокол) разряд по командным нормативам считается только тем, чей
       ЛИЧНЫЙ результат в этом же турнире входит в верхнюю половину (или
       треть — для МСМК) личного протокола, как и требуют нормативы.
     - Сознательные упрощения (программа о них честно предупреждает
       прямо на вкладке «Разряды»): категория судьи турнира не проверяется
       (программа не ведёт учёт судейских категорий); условие "не
       заменялся в ходе соревнования" не проверяется; пол для расчёта
       разряда берётся из общего поля турнира "пол участников", а не
       индивидуально по каждому спортсмену (в программе нет отдельного
       поля пола у спортсмена); у дисциплины «Форель» нет командного
       протокола вообще (сложение веса/длины по командам там не ведётся),
       поэтому командные разряды для неё не считаются — вкладка «Разряды»
       у форели показывает только личные результаты и честно объясняет
       почему командных нет.
       [Обновление в v8: командный зачёт у этой дисциплины появился —
       см. раздел "ЧТО НОВОГО (v8)" выше, командные разряды считаются.]

2. ПОЛУЗОНЫ — флажок «Делить зоны на полузоны» в общих данных турнира
   (доступен для форели и для "зонного весового" движка — донка/поплавок/
   блесна/мормышка; у лодок зон нет вообще, поэтому там этой настройки
   нет). При включении у каждого спортсмена при регистрации (или на
   вкладке «Зоны») появляется выбор не только зоны, но и полузоны (1 или
   2) на каждый тур. Место внутри зоны считается НЕЗАВИСИМО для каждой
   полузоны — то есть зона "А" фактически превращается в две отдельные
   мини-зоны "А/1" и "А/2" со своим собственным ранжированием мест, а
   дальше протокол и итоговое место считаются как обычно (это просьба
   из реального регламента — на крупных турнирах зону иногда физически
   делят пополам, чтобы участники не мешали друг другу на воде).

3. АВТОМАТИЧЕСКАЯ ЖЕРЕБЬЁВКА — флажок «Автоматическая жеребьёвка» в общих
   данных турнира и кнопка «🎲 Провести жеребьёвку» (появляется там же,
   когда флажок включён). Одно нажатие — и программа сама:
     - случайным образом назначает стартовый номер каждому участнику;
     - для каждого тура случайным образом раскидывает участников по
       зонам примерно поровну (а если включены полузоны — ещё и по
       полузонам внутри каждой зоны, тоже примерно поровну).
   Жеребьёвку можно провести повторно в любой момент до начала взвешивания
   (она просто перезапишет прежние зоны/номера) — программа перед этим
   переспрашивает подтверждение. Ручной ввод зон/номеров при этом никуда
   не делся — если жеребьёвка не нужна, флажок можно не включать и
   заполнять всё вручную, как раньше.

ЧТО НОВОГО (v6): собраны ВСЕ 6 дисциплин — полная программа
===========================================================================

Добавлены последние 4 дисциплины: донка, поплавочная удочка, блесна (со
льда), мормышка (со льда). У всех четырёх — ОДИНАКОВАЯ логика подсчёта
("зонный весовой" движок, как в оригинальном Excel-пакете), различия между
ними только в названии дисциплины в шапке протокола. Поэтому в программе
они делят один и тот же экран — при открытии турнира любой из этих четырёх
дисциплин откроется одна и та же страница, просто с названием именно вашей
дисциплины в заголовке.

Как считает "зонный весовой" движок (проверено по формулам реального
файла 4-Подсчет.xlsx):
  - Один спортсмен взвешивается ОДИН раз за тур (без периодов, в отличие
    от форели) — вес улова целиком, в своей зоне.
  - Санкции — индивидуальные, два вида: «снятие до взвешивания» (штрафной
    балл, худшее место) и «снятие после взвешивания» (в протоколе вес
    показывается как 0). Санкция всей команде целиком (а не спортсмену)
    в v1 не реализована — если нужно снять команду, снимите персонально
    каждого её участника, командная сумма это учтёт автоматически.
  - Команда — это не отдельное взвешивание, а просто отметка у спортсмена
    ("этот спортсмен ещё и в такой-то команде"). Баллы и место команды =
    сумма по ВСЕМ её отмеченным участникам, без отбора "лучших".
  - Место внутри зоны — среднее дробное при точном равенстве баллов (как
    и в форели/лодках). А вот итоговое место в общем протоколе (после
    суммирования обоих туров) — это уже ОБЫЧНОЕ спортивное ранжирование
    (равные делят одно и то же место, без дробей) — так буквально было
    в проверенных формулах реального протокола, это осознанное отличие
    от форели, а не ошибка.
  - Не реализовано в v1 (сознательно отложено, не блокирует работу):
    разряды/ЕВСК, деление зоны на полузоны, жеребьёвка как генератор
    (зона вводится вручную, как и везде в этой программе).
    [Обновление в v7: все три пункта реализованы — см. раздел
    "ЧТО НОВОГО (v7)" выше.]

Теперь полная программа охватывает все 6 дисциплин официального пакета:
лодки, форель, донка, поплавок, блесна, мормышка — лаунчер турниров
одинаково открывает нужный экран для любой из них.

===========================================================================
ЧТО НОВОГО (v5): добавлена дисциплина «Форель» (спиннинг с берега)
===========================================================================

Дисциплина «Ловля спиннингом с берега (форель)» вернулась и теперь полностью
работает — наравне с «Лодками», внутри той же самой программы (отдельная
программа не понадобилась: код формы полностью отдельный от «Лодок», ничего
общего не пересекается, и на скорость/надёжность уже работающей части
«Лодки» это не влияет).

Логика подсчёта (как в реальных правилах и в примере личной карты, который
вы прислали):
  - "Баллы" за период — это СУММА ДЛИН (см) всех рыб, пойманных спортсменом
    в этом периоде, а не отдельно вводимое судьёй число.
  - При равной сумме длины у нескольких спортсменов место определяется по
    количеству пойманных рыб: чем больше рыб — тем выше место (две рыбы по
    10 см лучше одной рыбы 20 см).
  - Перед началом соревнования — вкладка «Печать карт»: печатает ПУСТЫЕ
    бланки личной карты спортсмена (по образцу вашего файла) — отдельная
    карта на каждого спортсмена/тур/период, с полем для длины каждой рыбы
    и подписей судьи и спортсмена. Можно распечатать все карты сразу или
    только на конкретный тур/период/зону; число строк на карте по умолчанию
    30 (обычно рыб не больше), но можно увеличить. С этими бланками
    спортсмены и идут на воду.
  - Ввод данных — как в жизни: после периода судья открывает вкладку
    «Карты (периоды)», выбирает тур и период и для каждого спортсмена
    вписывает длины пойманных им рыб (через пробел) — так же, как это
    вручную переносится с заполненной бумажной карты в программу.
    Количество рыб и сумма длины считаются автоматически.
  - Протокол (вкладка «Протокол») показывает количество рыб, пойманных в
    каждом периоде, суммарную длину, место в зоне за тур, итоговое место за
    тур и итоговое место по сумме двух туров — как в официальном протоколе
    "Сводка ПТР".
  - Снятие спортсмена с тура (нарушение) — с какого периода снят — тоже
    поддерживается, как и в «Лодках»: после снятия занимает фиксированное
    последнее место в зоне до конца тура.

Если после всех показателей (сумма мест по зонам, сумма мест по периодам,
суммарная длина, лучший тур, тур №2) у нескольких спортсменов результат
совпадает АБСОЛЮТНО во всём — для этой дисциплины жребия нет вообще (это
не имеет отношения к "Лодкам", где такое правило другое). Всем спортсменам
в такой группе присваивается среднее арифметическое подряд идущих мест:
например, двое делят 5-6 место — обоим ставится 5.5; трое делят 3-4-5 —
всем ставится 4 (т.к. (3+4+5)/3=4), а следующий по счёту получает место 6.
Именно так и считает программа.

ЧТО НОВОГО (v4): общий лаунчер турниров
===========================================================================

Раньше программа держала только ОДИН турнир (лодки). Теперь при запуске
открывается список турниров ("лаунчер", как раньше был лаунчер в Excel-
версии):
  - можно создать НОВЫЙ турнир (название, дисциплина, место, дата) —
    для каждого турнира заводится своя отдельная папка с данными внутри
    data\tournaments\, турниры друг на друга не влияют;
  - можно ОТКРЫТЬ уже существующий турнир из списка;
  - можно УДАЛИТЬ турнир (безвозвратно, вместе с его данными).

Полноценно работает пока только дисциплина **«Лодки»** — регистрация,
взвешивание, официальный протокол. Остальные 4 дисциплины (донка,
поплавок, блесна, мормышка) можно выбрать при создании турнира — папка и
файл для них заводятся заранее, чтобы ничего не потерялось, — но при
открытии сейчас показывается страница «модуль в разработке». Это будет
дополняться постепенно.

Если вы раньше уже пользовались версией v2/v3 (только лодки, без
лаунчера) и обновляетесь на эту версию — при первом запуске новая версия
САМА найдёт старый файл data\лодки.sqlite и перенесёт его в реестр как
первый турнир. Все ранее введённые данные (турнир, судьи, команды, пары,
взвешивание) останутся на месте — просто теперь до них нужно один раз
дойти через лаунчер (кнопка «Открыть» на этом турнире в списке).

===========================================================================
ВАЖНО: как правильно запускать программу (чтобы данные не пропадали)
===========================================================================

Скачанный с GitHub Actions файл — это .zip-архив. Программу нужно:
  1. Скачать .zip
  2. РАСПАКОВАТЬ его целиком в обычную папку (правой кнопкой по архиву →
     "Извлечь всё" / "Extract All"), например на Рабочий стол или на флешку.
  3. Только ПОСЛЕ распаковки запускать .exe из этой обычной папки.

Если запустить .exe прямо ИЗ АРХИВА (двойной клик по файлу внутри окна
"Проводник — архив", без предварительной распаковки), Windows каждый раз
незаметно распаковывает программу во ВРЕМЕННУЮ папку — она разная при
каждом запуске и стирается после закрытия. Программа в этом случае честно
пишет файл(ы) базы данных в папку data рядом с собой, но это "рядом" —
временная папка, которая исчезает. Внешне это выглядит именно так, как
было в отчёте об ошибке: "ничего не сохраняется, при следующем открытии
пусто, никаких вариантов в списках".

Как проверить, что всё в порядке: в самом низу окна программы (мелким
серым текстом) теперь всегда показан РЕАЛЬНЫЙ путь к файлу базы данных —
на экране со списком турниров это файл реестра, например:
  Файл реестра турниров: C:\Users\Имя\Desktop\Рыбалка\data\реестр.sqlite
а внутри открытого турнира (экран «Лодки») — файл именно этого турнира:
  Файл базы данных турнира: C:\Users\Имя\Desktop\Рыбалка\data\tournaments\t0001\data.sqlite
Если в этой строке путь ведёт во что-то похожее на временную папку
(AppData\Local\Temp, _MEI... и подобное) — значит, программа запущена не
из распакованной папки, и это надо исправить (см. шаги 1-3 выше).

Также в этой версии исправлено и другое: сервер программы теперь
показывает понятную причину, если сохранение почему-то не удалось (раньше
ошибка "проглатывалась" молча, и было непонятно, что не так) — в правом
нижнем углу появится красное сообщение с текстом ошибки. А в форме
регистрации пары поле "ФИО спортсмена" теперь подсказывает уже введённых
ранее спортсменов (автозаполнение разряда и даты рождения при выборе) —
это отсутствовало раньше и могло восприниматься как "не показывает
варианты при заполнении".

===========================================================================
СПОСОБ 2 (проще): собрать в облаке через GitHub Actions — без своего
Windows-ПК и Mac, я подготовил всё нужное заранее
===========================================================================

В папке .github/workflows/build.yml лежит готовая настройка, которая сама
поднимает в облаке настоящую Windows-машину и настоящий Mac, собирает обе
программы и отдаёт готовые файлы для скачивания. Бесплатно.

Шаги:
1. Зарегистрируйтесь на https://github.com (бесплатно), если ещё нет аккаунта.
2. Создайте новый репозиторий (New repository), любое название,
   например "rybalka-lodki". Можно оставить приватным (Private) — для
   разовой сборки бесплатного лимита с запасом хватит; либо сделать
   публичным (Public), тогда ограничений по времени сборки нет вообще.
3. Загрузите ВСЮ папку rybalka_app (со всем содержимым, включая скрытую
   папку .github — при загрузке через веб-интерфейс GitHub перетащите
   всю распакованную папку целиком, не по одному файлу) через кнопку
   "Add file" → "Upload files" на странице репозитория.
4. Откройте вкладку "Actions" в репозитории. Сборка запустится сама
   (если появится запрос — нажмите "I understand my workflows, go ahead
   and enable them"). Если не запустилась сама — выберите workflow
   "Build Рыбалка-Лодки" слева и нажмите "Run workflow".
5. Подождите 2-5 минут, пока обе задачи (build-windows, build-macos)
   не станут зелёными.
6. Откройте завершившийся запуск, внизу страницы будет раздел "Artifacts"
   с двумя файлами: RybalkaLodki-Windows и RybalkaLodki-Mac. Скачайте
   оба (каждый скачается как .zip — распакуйте после скачивания).
7. Переименуйте, если хотите, и положите оба файла в одну папку на
   флешке рядом с папкой data — готово.

Если что-то не соберётся — вкладка Actions покажет красный крестик и лог
с ошибкой, можно прислать мне текст ошибки, разберём.
